# 🌤️ Weather App

A simple weather application built with **Vanilla JavaScript** that detects the user's location and displays the current weather information.

## 🚀 Features

* Detects user location using **IP Geolocation API**
* Fetches real-time weather data from **OpenWeather API**
* Displays temperature, weather description, and weather icon
* Toggle temperature units between **Kelvin, Fahrenheit, and Celsius**
* Automatically detects **day or night** to show the correct weather icon

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* Fetch API
* OpenWeather API

## 📦 APIs Used

* **IP API** – for detecting user location
* **OpenWeather API** – for weather data

## ⚙️ How It Works

1. The app detects the user's location using IP-based geolocation.
2. It sends the latitude and longitude to the OpenWeather API.
3. The API returns weather data such as temperature and weather condition.
4. The app displays the information along with the correct weather icon.
